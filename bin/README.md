# Самодостаточные restore-артефакты

Каталог `bin/` — часть дерева репозитория. Сюда `doBackup` выгружает
невидимые для Git файлы, достаточные для повторного импорта на устройство:

- `BACKUP-<device>-<stamp>.backup` — двоичный system backup;
- `BACKUP-<device>-<stamp>.unsafe.rsc` — полный `/export show-sensitive`.

На CHR путь тот же относительный: `REPO/raw/bin/` (host `/REPO/raw` = clone).
Содержимое, кроме этого README, игнорируется Git и не должно правиться вручную.

Не храните здесь единственную копию. Не открывайте и не передавайте файлы
агентам. Retention, шифрование и проверка restore — в отдельном закрытом storage.
