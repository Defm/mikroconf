# Локальные backup-файлы

Каталог служит local-only landing zone для бинарных backup-артефактов
RouterOS. Всё содержимое, кроме этого README, игнорируется Git.

Не помещайте сюда единственную копию. Не открывайте и не передавайте файлы
агентам. Долговременное хранение, шифрование, retention и регулярная проверка
restore должны выполняться отдельным закрытым backup storage.
