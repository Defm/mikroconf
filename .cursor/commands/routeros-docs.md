---

Найди в документации RouterOS сведения по запросу пользователя.

Порядок работы:

1. Начни с `routeros_search`.
2. Для точного свойства используй `routeros_lookup_property`.
3. Для иерархии команд используй `routeros_command_tree`.
4. Для чтения найденной страницы используй `routeros_get_page`.
5. При зависимости от версии проверь её инструментами rosetta.

Используй только данные RouterOS v7. Кратко изложи вывод и приведи URL
официальных источников, возвращённые rosetta. Если документация не
подтверждает утверждение, явно укажи это. Не обращайся к устройствам и не
используй `mikrotik-readonly`.
