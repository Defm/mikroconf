# Инструкции для агентов

## Границы работы

- Работайте только внутри этого репозитория.
- Не подключайтесь к RouterOS, SSH, SFTP, SCP, MCP-серверам и внешним системам без явного разрешения человека на конкретное действие.
- Не выполняйте deploy, import, restore, reset, reboot, package update или изменение конфигурации устройства.
- Не меняйте исторический raw-конвейер до появления подтверждённого долговременного хранения.

## Секреты и артефакты

- Никогда не читайте, не показывайте, не переносите и не коммитьте значения паролей, токенов, приватных ключей, сертификатов с ключом или backup-файлов.
- Для скриптов используйте ссылки на локальное хранилище секретов RouterOS (`$SECRET`) либо переменные, вводимые оператором во время восстановления.
- `bin/` и `src/safe/` могут содержать только свои `README.md` в Git.
- Полные exports считаются чувствительными, даже если их имя содержит `safe`.

## Изменения скриптов

- Канонический путь — `src/scripts`.
- Сохраняйте расширение `.rsc.txt`, имя RouterOS-скрипта и совместимость с установленными версиями.
- Изменение write-capable логики требует ручного review и плана отката.
- До cutover не меняйте производственный URL `master/scripts`; будущая цель — `master/src/scripts`.

## Проверка

Перед передачей результата выполните:

```sh
./tools/check-repository.sh
```

Не коммитьте и не публикуйте изменения автоматически.
