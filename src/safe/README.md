# Полные text restore-exports

Локальная рабочая зона для полных результатов `/export show-sensitive`,
необходимых для восстановления из исходного текста. Встроенные тела RouterOS
scripts сохраняются без дедупликации.

Название `safe` относится к историческому расширению `.safe.rsc` и не означает
отсутствие секретов. Git игнорирует всё, кроме этого README. Каталог не может
быть единственным долговременным хранилищем: retention и независимая копия
должны быть определены до выключения текущего backup pipeline.
